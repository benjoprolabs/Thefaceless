# Personal voice clones

Created by `python -m factory voice clone init`. Everything in this folder except
this README is **git-ignored** and written with owner-only permissions:

```
<clone-name>/
├── voice.json        status, owner, engine voice IDs, consent fingerprint
├── consent.md        signed ownership & consent declaration
├── samples/          your voice samples
└── verification/     your recording of the verification phrase
```

Only clone **your own voice**. Cloning another person's voice is not supported.
